# Operations System Specification Pack

هذه الحزمة هي المرجع الوظيفي المقترح لتطوير Vision Trade Operations System.

## الملفات

- `VisionTrade-Operations-Functional-Specification-v1.md`: المواصفات الوظيفية الكاملة.
- `permission-matrix-v1.csv`: مصفوفة الصلاحيات الأولية.
- `operation-transition-matrix-v1.csv`: انتقالات العملية والبوابات.
- `core-field-dictionary-v1.csv`: قاموس الحقول الأساسية ومصدرها وظهورها للعميل.
