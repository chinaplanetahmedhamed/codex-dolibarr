## الهدف

منع الالتباس عند رفع ملف أسعار مطابق لدفعة موجودة، وإظهار الفرق بوضوح بين المسودة والدفعة المنشورة الحالية والسجل المنشور، مع توفير إصلاح مقيد للدفعة المنشورة التي فقدت أعلام الأسعار الحالية.

## السياق الحالي

كان الاستيراد يعيد رقم الدفعة الموجودة عند تطابق الملف والإعدادات، بينما تعرض الواجهة رسالة توحي بإنشاء مسودة جديدة. الدفعة المنشورة لا يظهر لها زر نشر — وهذا صحيح — لكن الواجهة لم تشرح أنها منشورة وحالية أو محفوظة كسجل تاريخي.

## المتطلبات

1. عدم إنشاء دفعة مكررة للملف والإعدادات المطابقة.
2. إظهار رسالة دقيقة عند إعادة استخدام مسودة أو دفعة منشورة حالية أو تاريخية.
3. إظهار أعداد الأسعار المخزنة والمنشورة والحالية والمتاحة في بحث العميل.
4. جعل النشر وإعادة التفعيل عبر POST مع CSRF فقط.
5. منع إعادة تفعيل سجل أقدم أو دفعة حالية حتى بطلب مباشر.
6. عدم تغيير الأسعار أو البيانات خلال الاختبار؛ الاختبار التشغيلي لحالة النشر قراءة فقط.
