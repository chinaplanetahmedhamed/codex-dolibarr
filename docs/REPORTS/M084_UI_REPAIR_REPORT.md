# M084 — تقرير مصمم الواجهة بعد الإصلاح

الحالة: READY_FOR_INDEPENDENT_RECHECK — اكتمل التنفيذ المحلي للملاحظات الـ19، بانتظار قبول وكيل الفحص المستقل.

## النتيجة

أُصلحت الألوان والخطوط وأحجام النقر والتنسيق على الهاتف والتابلت، ومعالم الوصول وإدارة التركيز وحفظ اللغة. أصبح ترتيب المدير الافتراضي يبدأ بالتدخلات والتمويل والشحنات، مع احترام أي تخطيط محفوظ. لم يحدث نشر أو تعديل لبيانات الإنتاج أو الصلاحيات أو المحاسبة أو ملفات Dolibarr الأساسية.

## التحقق

- 104 حالات عرض نهائية للمدير والعميل: عربي/إنجليزي، 390 و1440، بلا مخالفات axe أو أخطاء JavaScript أو تمدد أفقي.
- 14 حالة تفاعل إضافية: الملاحة بعروض320/390/768/820/1024/1440، وحفظ اللغة، وEscape والتركيز، وتسمية رفع الملفات وعدم تداخل بطاقات الشحن.
- 194 فحص HTTP مع حسابات المدير والموظف وعميلين وحساب بلا صلاحيات؛ عزل العملاء والكيانات والبيانات الخاصة، وحفظ بيانات المال بعد التصفح.
- جميع19بطاقة: تغيير الحجم والإخفاء والإظهار والأسهم والحفظ وإعادة التحميل ورفض GET reset والاستعادة الافتراضية.
- 6 مجموعات انحدار للمحاسبة والشحن والعزل والمصدر PASS؛ وفحوص syntax وgit diff --check.
- أثناء التطوير فُحصت192حالة عرض بلا overflow أو أخطاءJS؛ نتائج المعالم الوسيطة حُلّت، والمصفوفة النهائية104هي دليل التصميم الحالي. الوكيل المستقل يعيد المصفوفة الأصلية كاملة.

## الملفات وحدود الإصلاح

تغييرات في واجهتي Customer Center وLogistics فقط، مع helper وأصول CSS/JS وملفي ترجمة جديدين. ملف deploy/releases/m084-runtime-files.txt يجمع24ملف تطبيق من إصلاح M084 الأساسي وإصلاح الواجهة. لا جداول أو schema أو صلاحيات أو إعدادات وحدة جديدة. الاختبارات التي تكتب تستهدف قاعدة QA المصطنعة المعزولة فقط؛ لا إرسال أو نشر أو ملفات عملاء حقيقية.

الشحن يحتفظ بمصطلحات دولية مثل ETA وBL، ومستند التصدير التجاري يحتفظ بالقالب الإنجليزي للطباعة. تم الإبقاء على CplBilingualTranslate للتوافق مع الاستدعاءات القديمة؛ شاشة بطاقة الشحنة تستخدم لغة المستخدم مباشرة.

الحدود: الاختبار على Chrome/macOS وبيانات QA، وليس قبولًا للإنتاج أو إثباتًا شاملًا لتوافق WCAG. يلزم قبول مستقل على Safari/Firefox وأجهزة حقيقية وقارئ شاشة فعلي. أخطاء500في الإنتاج منفصلة عن هذا الإصلاح وغير محسومة بهذا التقرير. التطبيق المحمول الأصلي خارج نطاق واجهة الويب الحالية.

الرجوع المحلي: الرجوع عن commit إصلاح الواجهة في فرع المراجعة فقط؛ لا rollback لقاعدة بيانات ولا تعليمات نشر. نسخة M084 السابقة9a34c9b محفوظة في تاريخ هذا الفرع. الوكيل المصمم يتوقف عن الكتابة بعد التجميد حتى انتهاء المراجع المستقل.
