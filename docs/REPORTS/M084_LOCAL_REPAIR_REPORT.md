# M084 — تقرير إصلاح لوحة التحكم

التاريخ: 16 سبتمبر 2026  
الحالة: إصلاحات محلية مختبرة؛ حادثة الإنتاج ما زالت مفتوحة. لم يحدث نشر إلى staging أو production.

## النتيجة

أُصلحت عيوب مؤكدة في الروابط، وتصنيفات الشحن، والتاريخ، وكتابة البيانات من طلبات التصفح. **أخطاء 500 واختفاء صفوف المشاريع على الإنتاج لم يُعلن حلها**: الصفحات نفسها، باستخدام الكود المسجّل للنشر وDolibarr 23.0.3، اكتملت في البيئة المحلية حتى قبل الإصلاح. يلزم سجل PHP الفعلي لتحديد فرق التشغيل أو الملفات أو الإعدادات.

لا توجد أدلة كافية لنسبة الحادثة إلى Gemini أو الجزم بأن commit خاطئًا نُشر. سجل النشر يشير إلى M083-R08 / `d21c0ca30150e1b885586f1c337773b6c71f7802`؛ لم تُجرَ مقارنة جديدة لملفات الإنتاج أو قاعدة بياناته في هذه المرحلة.

الرابط القديم `invoice.php?id=...` دون عميل يبقى مرفوضًا للموظف الداخلي. أُصلح مصدر الرابط؛ لم تُخفّف حماية صفحة الفاتورة ولم يُستنتج العميل من رقم فاتورة يرسله المستخدم.

## الاختبارات والأدلة

- 194 تحققًا عبر HTTP بجلسات تسجيل دخول حقيقية لمدير وموظف وعميلين وحساب بلا صلاحيات. البيانات تجريبية فقط.
- 16 عرضًا عبر المتصفح: لوحة التحكم والمشاريع والشحنة والفواتير، بعرض 1440 و390، والعربية والإنجليزية. لا أخطاء JavaScript أو تجاوز لعرض الصفحة. عرض الهاتف محاكاة متصفح، وليس جهازًا فعليًا.
- البطاقات الـ19: تغيير الحجم، الإخفاء، الإظهار، ترتيب بلوحة المفاتيح؛ حفظ ثم إعادة تحميل، رفض إعادة الضبط عبر GET، ثم إعادة الضبط المقصودة وإعادة تحميلها.
- 6 اختبارات منفصلة للمالية متعددة العملات، رحلة الشحنة، عقد M083، وضوح بوابة العميل، تدفق الشحن M078، وتنسيق M084؛ جميعها ناجحة. اختبار عزل العميل القائم نجح أيضًا على قاعدة QA.
- فحص صياغة PHP لكل الملفات المعدّلة، وصياغة JavaScript وأداة التشخيص، و`git diff --check`.
- بصمات سجلات الاختبار أثبتت أن التصفح لم يغيّر البطاقات أو الفواتير أو المدفوعات أو الأموال أو الشحنات. المزامنة المقصودة غيّرت بطاقتها التجريبية فقط. لم تتغير معادلات الحساب أو العملات أو أسعار الصرف.

اختبارات M084 موجودة في `deploy/tests/test_m084_*`؛ الحارس `m084_qa_state.php` لا يقبل إلا قاعدة محلية باسم `m084_qa_<random>` وعنوان QA المحدد. متطلبات تشغيلها: `M084_QA_ROOT`، و`M084_PHP`، وللمتصفح `M084_PLAYWRIGHT` و`M084_OUTPUT`. سجلات البيانات التجريبية 101/102، وشركة أخرى 201، وحسابات QA منفصلة. ملف كلمات المرور محلي خاص ولم يدخل Git أو الحزمة.

## ما لم يُحسم

1. 35 رابطًا أعطت 500 في الفحص الأصلي: لم يُعد إنتاج هذا الخطأ محليًا. يلزم سجل أخطاء الإنتاج قبل اعتماد السبب والإصلاح.
2. 5 صفحات أعطت 200 مع محتوى مبتور: تطبيع التواريخ اختُبر محليًا، لكن السبب الفعلي في الإنتاج غير مثبت.
3. ملفات CSS/JS الأربع غير الموجودة لـ Oblyon وWhatsApp: لم تظهر مراجعها في المصدر المختار؛ يلزم فحص تسجيلات الوحدات في بيئة التشغيل. لم تُفعّل وحدات أو تُعدّل إعدادات إنتاج لإخفاء الأعراض.
4. اسم بيئة الإنتاج كان غير مضبوط في الفحص السابق؛ لم تُغيّر إعداداته ضمن الإصلاح المحلي.
5. هذه ليست شهادة تشغيل شامل للإنتاج. ملف التغطية يربط حالة كل واحد من الروابط الـ576 السابقة بالعمل الحالي. جرد الأزرار السابق يضم 3496 ظهورًا، وليس 3496 إجراءً منفذًا. لم تُجرَ عمليات نشر مستندات أو إرسال رسائل أو مدفوعات حقيقية أو حذف بيانات أعمال.
6. تطبيق الهاتف الأصلي لم يُبنَ أو يُختبر هنا. الصفحات المتجاوبة وعقود الوصول المشتركة اختُبرت؛ مصدر التطبيق لم يتغير.

## ملاحظة تشغيل محلية

إنشاء نسخة مخطط QA من 452 جدولًا تسبب لاحقًا في بلوغ MySQL المحلي حد الملفات المفتوحة (`FD_SETSIZE=1024`). أُعيد تشغيل MySQL المحلي إغلاقًا سليمًا بنفس إعدادات MAMP لاستعادة الاتصال، دون ترقية أو تغيير بيانات/إعدادات. عادت صفحتا تسجيل الدخول المحلية الأصلية وQA إلى العمل. يوصى بمثيل قاعدة بيانات مستقل بالكامل عند إعادة بناء مخطط بهذا الحجم. بيانات النسخة الأصلية لم تُنسخ، عدا جداول المرجع العامة وتعريفات صلاحيات عامة لحسابات QA التجريبية.

## الخطوة التالية

أُعد ملف `deploy/tools/m084-production-readonly-diagnostics.sh` لقراءة إصدار PHP وأخطاء الحادثة المنقّحة فقط من الحاوية الثابتة `vision_erp`. لا يقرأ قاعدة البيانات أو إعدادات الأسرار ولا يغيّر ملفات أو ينشر. **لم يُنفّذ**: حساب SSH المقيد لا يمنح هذا الأمر، ووجود جلسة Termius ذات صلاحية root لا يمنح تلقائيًا إذن استخدامها.

بعد إتاحة سجل الخطأ: تثبيت السبب، استكمال الإصلاح والاختبارات، ثم مقارنة الإصدار الفعلي واعتماد حزمة واحدة لاختبار staging. نشر الإنتاج يبقى بإذن مستقل محدد. المرشح الحالي ليس إذن نشر أو إعلان معالجة الحادثة.
